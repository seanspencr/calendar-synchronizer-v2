# Setup backend server
### Prerequisites : add .env in the root project
1. Run in your terminal \
``` npm i -g @nestjs/cli ``` \
``` npm i ``` \
``` cd src ``` \
``` npx prisma generate```

3. start the backend server \
``` npm start ```

# Setup frontend
### Prerequisites : add .env in the root project
1. Install expo and dependencies \
``` npm install expo ``` \
``` npx expo install ``` 

2. Run the expo
- web \
``` npm run web ```
- android \
``` npm run android ```
